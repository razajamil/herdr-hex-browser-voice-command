Voice Router — Routes

Each rule matches a browser URL and sends your voice transcript to a herdr tab/pane. The first matching rule wins.

URL pattern syntax — * matches anything; {workspace} captures the part used to find the herdr workspace (matched against workspace label / worktree folder, tolerant of a fix-/feat- prefix).
Example: http://{workspace}.payroll.localhost/* on http://rwr-1234-heardroom.payroll.localhost/v2 → workspace key rwr-1234-heardroom, delivered to tab main / pane agent.
